# Página de una experiencia

La **página de una experiencia** es donde el visitante toma la decisión de reservar. Es la combinación de dos cosas: la **narrativa** (publicación) y la **información comercial** (experiencia).

---

## Qué ve el cliente

Al abrir la página de una experiencia, el cliente ve:

### En la parte superior

- **Nombre de la experiencia** — El nombre público que configuraste.
- **Imagen de portada** — La foto principal.
- **Descripción corta** — El resumen de 2-3 líneas.
- **Precio desde** — El precio mínimo disponible.
- **Botón de acción** — "Reservar", "Solicitar" o "Comprar" según el modo de venta.

### En el cuerpo de la página

- **El contenido editorial** — Los bloques de texto, imágenes, galería y demás secciones que creaste en la publicación vinculada.
- **Descripción completa** — El texto largo de la experiencia.
- **Horarios disponibles** — Si la experiencia tiene horarios activos, aparecen aquí para que el cliente elija.
- **Precios** — Los niveles de precio activos.
- **Complementos** — Los extras opcionales disponibles.

---

## De dónde viene cada cosa

| Lo que ve el cliente     | De dónde viene en el panel               |
| ------------------------ | ---------------------------------------- |
| Nombre de la experiencia | Experiencia → Info → Nombre público      |
| Imagen de portada        | Experiencia → Info → Imagen de portada   |
| Descripción corta        | Experiencia → Info → Descripción corta   |
| Precio                   | Experiencia → Precios → Precios activos  |
| Horarios disponibles     | Experiencia → Horarios (o Agenda global) |
| Contenido editorial      | Publicación vinculada → Secciones        |
| Complementos             | Experiencia → Complementos vinculados    |

---

## ¿Qué pasa si falta algún elemento?

- Si **no hay precio activo**, el botón de compra no aparece o muestra "No disponible".
- Si **no hay horarios**, el selector de fecha no aparece.
- Si **no hay publicación vinculada**, la página solo muestra la información básica de la experiencia sin contenido editorial.

---

## Optimizar la página de una experiencia

Para tener la mejor conversión (que los visitantes se conviertan en clientes):

1. **Foto de portada impactante** — La primera impresión es visual.
2. **Descripción corta que enganche** — Las primeras líneas deben generar curiosidad o deseo.
3. **Precio claro y visible** — El visitante no debe tener que buscar cuánto cuesta.
4. **Horarios actualizados** — Nada desanima más que ver que no hay fechas disponibles.
5. **Contenido editorial rico** — Cuanta más historia y emoción transmitas, más fácil la decisión.
