# Configuración

La sección de **Configuración** contiene los ajustes generales de la plataforma: las plantillas de correos automáticos y otros parámetros del sistema.

---

## Cómo llegar

En el menú lateral ve a **Sistema → Configuración**.

---

## Plantillas de notificación

Las plantillas definen el contenido de los correos que la plataforma envía automáticamente a los clientes. Puedes editar el texto de cada correo sin tocar nada técnico.

### Tipos de correo automático

| Correo                 | Cuándo se envía                                  |
| ---------------------- | ------------------------------------------------ |
| Confirmación de compra | Al confirmar una orden                           |
| Ticket emitido         | Al generarse un ticket                           |
| Recordatorio           | Antes de la fecha de la experiencia              |
| Solicitud recibida     | Cuando el cliente envía una solicitud de reserva |
| Cotización enviada     | Cuando el equipo responde con una cotización     |
| Solicitud confirmada   | Cuando se confirma una solicitud                 |
| Solicitud rechazada    | Cuando se rechaza una solicitud                  |
| Cancelación            | Cuando se cancela una orden o un horario         |

### Editar una plantilla

1. Selecciona la plantilla que quieres editar.
2. Puedes modificar el asunto del correo y el cuerpo del mensaje.
3. Usa las **variables disponibles** para incluir información dinámica (nombre del cliente, nombre de la experiencia, fecha, etc.). Las variables se muestran en la misma pantalla.
4. Guarda los cambios.

> **No borres las variables** que aparecen entre llaves `{{ }}` — son los datos que el sistema llena automáticamente. Solo modifica el texto que los rodea.

---

## Ajustes generales

Dependiendo de la versión de tu plataforma, aquí también puedes encontrar:

- **Nombre del negocio** — Cómo se llama tu negocio en los correos y el sitio.
- **Correo de contacto** — La dirección a la que los clientes pueden escribirte.
- **Idioma predeterminado** — El idioma principal de la interfaz y los correos.

---

## Consejos

- Revisa todas las plantillas antes de empezar a vender — asegúrate de que el tono y la información sean correctos.
- Personaliza el correo de "Confirmación de compra" para dar una bienvenida cálida al cliente.
- El correo de "Recordatorio" es clave — envíalo 24 horas antes de la experiencia para reducir las ausencias.
