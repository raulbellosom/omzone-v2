# Paquetes y pases

OMZONE ofrece dos formas de que los clientes compren acceso a múltiples sesiones con condiciones especiales: los **paquetes** y los **pases**. Aunque parecidos, tienen propósitos distintos.

---

## ¿Cuál es la diferencia?

| Característica      | Paquete                                            | Pase                                                   |
| ------------------- | -------------------------------------------------- | ------------------------------------------------------ |
| **Qué es**          | Un conjunto fijo de experiencias o sesiones        | Un crédito recargable para usar en múltiples sesiones  |
| **Cómo se consume** | Se usa completo, en el orden que define el paquete | Se descuentan créditos cada vez que el cliente reserva |
| **Cuándo expira**   | Cuando se agotan las sesiones incluidas            | Tiene fecha de vencimiento o límite de créditos        |
| **Ejemplo típico**  | "Paquete de 5 sesiones de yoga + 1 masaje"         | "Pase mensual ilimitado" o "Pase de 10 clases"         |

> **Regla simple:** Usa **paquetes** cuando vendes una combinación específica de experiencias. Usa **pases** cuando vendes créditos para que el cliente elija cuándo y qué experiencia usar.

---

## Paquetes

### Qué es un paquete

Un paquete agrupa varias experiencias o sesiones en una sola compra, generalmente con un precio especial. El cliente compra el paquete completo y recibe un ticket por cada sesión incluida.

### Cuándo usar paquetes

- Cuando quieres vender combinaciones predefinidas: "Retiro + 3 sesiones de seguimiento".
- Cuando ofreces un precio especial por comprar varias sesiones juntas.
- Cuando las sesiones tienen un orden o una secuencia específica.

### Cómo crear un paquete

1. En el menú lateral, ve a la sección correspondiente (próximamente dentro de **Catálogo**).
2. Haz clic en **Nuevo paquete**.
3. Ponle un nombre y descripción.
4. Agrega las experiencias o sesiones que lo componen.
5. Define el precio del paquete.
6. Actívalo.

---

## Pases

### Qué es un pase

Un pase funciona como un monedero de créditos para sesiones. El cliente compra el pase y luego lo usa para reservar experiencias compatibles, descontando créditos de su saldo cada vez.

### Tipos de pase

| Tipo              | Cómo funciona                                                                  |
| ----------------- | ------------------------------------------------------------------------------ |
| Pase por sesiones | El cliente tiene un número fijo de sesiones. Cuando se agotan, el pase vence.  |
| Pase por tiempo   | El cliente puede asistir ilimitadamente durante un periodo (semanal, mensual). |

### Cuándo usar pases

- Para clientes frecuentes que asisten varias veces a la semana o al mes.
- Cuando quieres ofrecer membresías o abonos.
- Cuando el cliente necesita flexibilidad para elegir fechas y horarios.

### Cómo crear un pase

1. Ve a la sección de **Pases** en el panel.
2. Haz clic en **Nuevo pase**.
3. Define el nombre, la descripción y el tipo (por sesiones o por tiempo).
4. Si es por sesiones: cuántas incluye.
5. Si es por tiempo: la duración (7 días, 30 días, etc.).
6. Define el precio.
7. Selecciona qué experiencias acepta este pase.
8. Actívalo.

---

## Consultar el saldo de un pase

Para ver cuántos créditos le quedan a un cliente:

1. Ve a **Ventas → Clientes**.
2. Abre la cuenta del cliente.
3. En la sección de pases verás todos los pases activos con su saldo y fecha de vencimiento.

---

## Preguntas frecuentes

**¿Un cliente puede tener varios pases activos al mismo tiempo?**
Sí. Cada pase es independiente.

**¿Qué pasa si el pase vence antes de que el cliente use todos sus créditos?**
Los créditos no usados se pierden al vencer el pase. Por eso es importante comunicarle al cliente la fecha de vencimiento con anticipación.

**¿Puedo extender la vigencia de un pase?**
Sí, desde la cuenta del cliente puedes ajustar la fecha de vencimiento de un pase activo.

**¿Los pases y paquetes aparecen en las órdenes?**
Sí. Cada compra de un pase o paquete genera una orden que puedes ver en **Ventas → Órdenes**.
