# Secciones y bloques

El contenido de cada publicación se construye mediante **secciones**. Cada sección es como una fila de la página — puede contener texto, imágenes, una galería, un listado de preguntas y respuestas, etc.

---

## Cómo funciona

Imagina tu página como una pila de bloques apilados de arriba hacia abajo:

```
┌──────────────────────────────┐
│   Sección: Hero (portada)    │
├──────────────────────────────┤
│   Sección: Texto + imagen    │
├──────────────────────────────┤
│   Sección: Galería de fotos  │
├──────────────────────────────┤
│   Sección: Preguntas y respuestas │
├──────────────────────────────┤
│   Sección: Llamada a la acción │
└──────────────────────────────┘
```

Tú decides cuántas secciones tiene la página y en qué orden aparecen.

---

## Cómo llegar

Las secciones se gestionan dentro de cada publicación. Para acceder:

1. Ve a **Contenido → Publicaciones**.
2. Abre la publicación que quieres editar.
3. En la pestaña de contenido verás la lista de secciones.

---

## Tipos de sección

| Tipo                 | Para qué sirve                                                   |
| -------------------- | ---------------------------------------------------------------- |
| Texto                | Un bloque de texto largo (descripción, narrativa, artículo)      |
| Imagen + Texto       | Texto al lado de una imagen                                      |
| Galería              | Cuadrícula de fotos                                              |
| Preguntas frecuentes | Listado de preguntas y respuestas desplegables                   |
| Video                | Insertar un video de YouTube o Vimeo                             |
| Llamada a la acción  | Un botón o banner que invita al visitante a reservar o contactar |
| Beneficios           | Listado de puntos o características destacadas                   |
| Testimonios          | Opiniones de clientes                                            |

---

## Agregar una sección

1. En la vista de secciones de la publicación, haz clic en **Agregar sección**.
2. Elige el tipo de sección que quieres añadir.
3. Completa el contenido (texto, imágenes, etc.) en el formulario que aparece.
4. Guarda la sección.

---

## Reordenar secciones

Puedes arrastrar las secciones para cambiar el orden en que aparecen en la página. Solo arrastra el ícono de mover (⠿) que aparece a la izquierda de cada sección.

---

## Activar o desactivar una sección

Cada sección tiene un interruptor para activarla o desactivarla sin borrarla. Útil para ocultar temporalmente una parte del contenido sin eliminarla.

---

## Eliminar una sección

Usa el menú de opciones (⋮) de la sección y selecciona **Eliminar**. Esta acción no se puede deshacer, así que asegúrate antes de confirmar.

---

## Consejos para construir páginas atractivas

- Comienza con una sección de tipo **Hero** o **Texto** que capture la atención.
- Alterna entre texto e imágenes para hacer la página más visual.
- Usa la sección de **Llamada a la acción** cerca del final para invitar al visitante a reservar.
- No sobrecargues la página — 4 a 6 secciones suelen ser suficientes para una experiencia.
