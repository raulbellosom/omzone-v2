# Venta asistida

La **venta asistida** te permite crear una orden directamente desde el panel, en nombre de un cliente. Es útil cuando el cliente no puede o no quiere comprar por su cuenta en el sitio web.

---

## Cuándo usar la venta asistida

- El cliente está contigo en persona o por teléfono y quiere pagar de inmediato.
- La experiencia es de tipo "Asistida" (solo se puede vender desde el panel).
- El cliente tuvo un problema técnico al intentar comprar.
- Quieres crear una orden sin cobro en línea (por ejemplo, para una venta corporativa).

---

## Cómo llegar

En el menú lateral ve a **Ventas → Venta asistida** o busca el botón **Nueva venta asistida** desde la sección de Órdenes.

---

## Crear una venta asistida paso a paso

### Paso 1: Seleccionar la experiencia

Busca y selecciona la experiencia que el cliente quiere comprar. Solo se muestran las experiencias activas con al menos un precio activo.

### Paso 2: Elegir horario y precio

Si la experiencia tiene horarios, selecciona el que corresponde. Después elige el precio aplicable.

### Paso 3: Seleccionar o registrar al cliente

Busca al cliente por su nombre o correo electrónico. Si aún no tiene cuenta registrada, puedes crear una nueva directamente desde este paso.

### Paso 4: Agregar complementos (opcional)

Si la experiencia tiene complementos disponibles, selecciona los que el cliente quiere incluir.

### Paso 5: Confirmar la orden

Revisa el resumen de la compra y haz clic en **Confirmar orden**. El sistema:

- Crea la orden con estado "Confirmada".
- Genera el ticket si la experiencia lo requiere.
- Envía la confirmación por correo al cliente.

---

## Cobro en ventas asistidas

En una venta asistida el sistema **no procesa el pago automáticamente**. El cobro debes gestionarlo por tu cuenta (efectivo, transferencia, terminal bancaria). La orden se crea como confirmada asumiendo que el pago fue recibido.

> Asegúrate de registrar el pago en tu sistema de caja o contabilidad separado.

---

## Ver las ventas asistidas

Las órdenes creadas mediante venta asistida aparecen en **Ventas → Órdenes** junto con todas las demás, pero tienen una etiqueta que indica que fueron creadas manualmente desde el panel.
