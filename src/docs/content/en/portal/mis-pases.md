# My passes

Passes let you attend multiple sessions without buying each one individually. If you practice regularly, a pass is the most convenient (and usually the most affordable) way to book.

---

## Getting there

From your portal, click **My passes** in the menu.

---

## Types of passes

| Type             | How it works                                                           |
| ---------------- | ---------------------------------------------------------------------- |
| Session pass     | You bought a set number of sessions — one is deducted per attendance.  |
| Time-based pass  | Unlimited access for a defined period (weekly, monthly, etc.).         |

---

## Your pass list

You'll see all your passes — active and expired. Each one shows:

- **Pass name** — What it covers.
- **Remaining balance** — How many sessions you have left (for session passes).
- **Expiry date** — How long it's valid.
- **Status** — Active, expired, or used up.

---

## Using a pass to book

When you book a compatible experience:

1. At checkout, the system detects your active pass automatically.
2. It asks if you'd like to use the pass instead of paying.
3. Confirm, and one session is deducted from your balance.

---

## Usage history

Inside each pass you can see a full log of when and which experiences you used it for.

---

## Common pass questions

**Can I use my pass for any experience?**
Only experiences that are compatible with your pass. Each pass specifies which experiences it covers.

**What happens when my pass expires with sessions still left?**
Unused sessions are forfeited at expiry. Make sure to use your pass before it runs out.

**Can I have more than one pass at a time?**
Yes. Each pass is independent and you can hold multiple at once.

**How do I renew my pass?**
Purchase a new one from the **Explore** section before your current pass expires.

**Can I transfer my pass to someone else?**
No. Passes are personal and non-transferable.
