# Locations

A **location** is a physical place where your experiences happen — a studio address, an outdoor space, a retreat property, or a partner venue.

---

## Creating a location

1. Go to **Locations** in the sidebar.
2. Click **New location**.
3. Fill in:
   - **Name** — What this place is called (e.g., "Main Studio", "Oceanfront Terrace").
   - **Address** — Full street address.
   - **City** — City name.
   - **Description** — A short description for clients (optional).
   - **Map link** — A Google Maps or similar URL so clients can get directions easily.
   - **Photo** — An image of the space (optional but recommended).
4. Save.

---

## Using locations in schedules

When you create a schedule, you assign a location to it. This tells both your team and your clients exactly where the session takes place.

Clients can see the location name and address on:
- The experience page on the public site
- Their booking confirmation email
- Their ticket

---

## Multiple locations

If you run experiences in different places, each one should have its own location entry. This lets you:
- Filter the agenda by location
- Track capacity per space
- Show clients accurate directions

---

## Editing a location

You can update a location's details at any time. Changes apply to future schedules — past events aren't affected.

---

## Deactivating a location

If you stop using a space, set it to **Inactive**. It won't appear as an option for new schedules, but historical data is preserved.
