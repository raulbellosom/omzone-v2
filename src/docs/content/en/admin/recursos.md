# Resources

A **resource** is anything you need in order to run a session: a person (instructor, facilitator), a room (yoga studio, meditation hall), or a piece of equipment (sound bath instruments, massage table).

Resources are assigned to schedules so the system can track availability and prevent double-booking.

---

## Types of resources

| Type      | Examples                                        |
| --------- | ----------------------------------------------- |
| Person    | Instructor, guide, therapist, facilitator       |
| Space     | Main studio, outdoor terrace, retreat room      |
| Equipment | Sound bath set, projector, mats, massage table  |

---

## Creating a resource

1. Go to **Resources** in the sidebar.
2. Click **New resource**.
3. Fill in:
   - **Name** — The instructor's name, room name, or equipment label.
   - **Type** — Person, space, or equipment.
   - **Capacity** — For spaces: maximum number of people. For people: usually 1 (one session at a time).
   - **Description** — Optional bio or notes.
4. Save.

---

## Assigning resources to a schedule

When you create or edit a schedule:
1. Find the **Resources** field.
2. Select the instructor, room, and any equipment needed.
3. Save the schedule.

If a resource is already booked at the same time, the system will warn you before saving.

---

## Resource availability

The system uses resource assignments to prevent conflicts. If you try to schedule two sessions at the same time with the same instructor or in the same room, you'll get a conflict warning.

---

## Instructors on the public site

Resources don't automatically appear on the public site. To feature an instructor's bio and photo:
1. Open the publication linked to the experience.
2. Add an **About the instructor** or **Team** section.
3. Write the bio, upload a photo, and save.

---

## Deactivating a resource

If an instructor leaves or a room is no longer available:
1. Open the resource.
2. Set its status to **Inactive**.

Inactive resources won't appear as options when creating new schedules, but existing schedules that used them are unaffected.
