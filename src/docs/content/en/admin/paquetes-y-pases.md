# Packages & Passes

Packages and passes let you sell multiple sessions in a single purchase, often at a better price than buying each one individually. They're a powerful tool for building client loyalty and recurring revenue.

---

## Packages vs. passes — what's the difference?

| Feature          | Package                                | Pass                                       |
| ---------------- | -------------------------------------- | ------------------------------------------ |
| How it works     | Fixed number of sessions purchased together | Access to sessions (by count or time period) |
| Flexibility      | Tied to specific experiences           | Can cover a range of compatible experiences |
| Example          | "10 Pilates sessions"                  | "Monthly unlimited access" or "20-session pass" |

---

## Creating a package

1. Go to **Packages & Passes** in the sidebar.
2. Click **New package**.
3. Fill in:
   - **Name** — What clients will see.
   - **Description** — Who it's for and what it includes.
   - **Number of sessions** — How many sessions are included.
   - **Compatible experiences** — Which experiences can be used with this package.
   - **Price** — The total price of the package.
   - **Validity** — How many days the client has to use all sessions (from purchase date).
4. Set the status to **Active**.
5. Save.

---

## Creating a pass

1. Click **New pass**.
2. Fill in:
   - **Name** — e.g., "Unlimited Monthly Pass".
   - **Type** — By sessions (fixed number) or by time period (unlimited within a date range).
   - **Compatible experiences** — Which experiences it covers.
   - **Price** — What it costs.
   - **Expiry** — Number of days, or a specific end date.
3. Activate and save.

---

## How clients use a package or pass

When a client with an active pass or package books a compatible experience, the system automatically detects it at checkout and offers the option to use their pass instead of paying again. One session is deducted from their balance.

---

## Monitoring usage

From each package or pass entry, you can see:
- How many have been sold.
- For each active pass: who holds it, how many sessions remain, and when it expires.

---

## Pass expiry

When a pass expires, unused sessions are forfeited. The system will not automatically extend a pass — the client needs to purchase a new one. Consider sending a reminder notification before expiry (see **Settings → Notifications**).
