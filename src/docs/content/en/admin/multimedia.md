# Media

The **Media** library is where all your photos and files live. Any image you want to use in a publication — cover photos, instructor portraits, gallery images — is uploaded here first.

---

## Uploading files

1. Go to **Media** in the sidebar.
2. Click **Upload** or drag and drop files onto the upload area.
3. Supported formats: **JPG, PNG, WebP**
4. Maximum file size: **10 MB** per file.
5. The file appears in the library once uploaded.

---

## Organizing media

Files are organized by upload date by default. You can also:
- Search by filename.
- Filter by type.
- See which publications each file is used in.

---

## Using media in publications

When you add an image block or set a cover photo in a publication:
1. A file picker opens.
2. Browse or search the media library.
3. Click the image you want to use.

You don't need to re-upload the same image every time — once it's in the library, you can reuse it anywhere.

---

## Image quality tips

The quality of your photos directly affects how professional the site looks. Some guidelines:

| Good photos                                | Photos to avoid                             |
| ------------------------------------------ | ------------------------------------------- |
| Natural light, clear subjects              | Dark, blurry, or grainy images              |
| Authentic moments from sessions            | Generic stock photos                        |
| Horizontal (landscape) for covers          | Heavily filtered or over-edited             |
| Minimum 1200px wide for cover images       | Screenshots from a phone at low resolution  |

---

## Deleting media

You can delete files from the library if they're no longer needed. Before deleting, check whether the file is being used in any active publications — removing it will leave a broken image in that publication.
