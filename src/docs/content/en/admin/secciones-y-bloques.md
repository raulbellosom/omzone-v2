# Sections & blocks

Publications are built with **sections** — each one is a content area on the page. Inside sections, you add **blocks**: text, images, galleries, call-to-action buttons, and more.

---

## The structure

```
Publication
  └── Section 1 (e.g., Hero)
        ├── Block: Full-width image
        └── Block: Headline + tagline
  └── Section 2 (e.g., About the experience)
        ├── Block: Long-form text
        └── Block: Image grid
  └── Section 3 (e.g., About the instructor)
        ├── Block: Profile image
        └── Block: Bio text
```

---

## Adding a section

1. Open a publication.
2. Scroll to the sections area and click **Add section**.
3. Choose a section template (hero, text + image, gallery, team, etc.) or start blank.
4. Give the section a name for your reference.
5. Save.

---

## Adding blocks to a section

1. Open a section.
2. Click **Add block**.
3. Choose the block type:
   - **Text** — Rich text, headers, lists, links
   - **Image** — Single photo with optional caption
   - **Gallery** — Multiple photos in a grid
   - **Video** — Embedded video
   - **Call to action** — Button that links to a booking or URL
   - **Quote** — Highlighted pull quote
4. Fill in the content.
5. Save.

---

## Reordering sections

Drag sections up or down to change the order they appear on the page.

---

## Reordering blocks within a section

Same thing — drag blocks within a section to reorder them.

---

## Tips for great publications

- **Start strong** — Your first section should immediately answer: "What is this, and why should I care?"
- **Use real photos** — Stock images feel impersonal. Authentic photos of the space and people build trust.
- **Keep text scannable** — Short paragraphs, clear headers, bullet points where it makes sense.
- **One clear CTA** — Don't confuse clients with five different buttons. One "Book now" per page is enough.
- **Mobile first** — Many clients will see this on their phone. Preview it at mobile size before publishing.
