# The experience page

The **experience page** is where visitors decide to book. It combines two things: the **narrative** (the publication) and the **commercial details** (the experience itself).

---

## What the visitor sees

### At the top
- **Experience name** — The public name you set.
- **Cover image** — The main photo.
- **Short description** — Your 2-3 line summary.
- **Starting price** — The lowest active price.
- **Action button** — "Book now", "Reserve", or "Request" depending on the sale mode.

### In the body
- **Editorial content** — The sections and blocks from the linked publication: text, photos, gallery, instructor bio.
- **Full description** — The longer description of the experience.
- **Available dates** — If there are active schedules, they appear here for clients to choose from.
- **Pricing** — All active price tiers.
- **Add-ons** — Optional extras available for this experience.

---

## Where each element comes from

| What the visitor sees        | Where it comes from in the admin panel                    |
| ---------------------------- | --------------------------------------------------------- |
| Experience name              | Experience → Info → Public name                           |
| Cover image                  | Experience → Info → Cover image                           |
| Short description            | Experience → Info → Short description                     |
| Pricing                      | Experience → Pricing → Active price tiers                 |
| Available dates              | Experience → Schedules (or Global agenda)                 |
| Editorial content            | Linked publication → Sections                             |
| Add-ons                      | Experience → Linked add-ons                               |

---

## What happens when something is missing

- **No active price** — The booking button won't appear or shows "Not available."
- **No schedules** — The date picker won't appear.
- **No linked publication** — The page shows only basic info with no editorial content.

---

## Making the most of an experience page

To maximize bookings:

1. **Compelling cover photo** — First visual impression.
2. **Short description that hooks** — The first two lines should make someone want to read more.
3. **Visible, clear pricing** — Visitors shouldn't have to hunt for the price.
4. **Up-to-date schedules** — Nothing discourages a visitor more than finding no available dates.
5. **Rich editorial content** — The more story and emotion you convey, the easier the decision.
