# Sell a session package

A **package** bundles several sessions into a single purchase — convenient for clients and great for your recurring revenue.

**Example:** "10-session yoga package — valid for 90 days."

---

## How packages work

1. The client buys the package in one transaction.
2. They receive a pass with a set number of sessions.
3. Each time they book a compatible experience, one session is deducted from their balance.

---

## Step 1 — Plan the package

Before creating it, decide:

- **How many sessions** does the package include?
- **Which experiences** can it be used for?
- **How long is it valid?** (30 days? 90 days? 6 months?)
- **What's the price?** (And is there an early-bird or limited-time offer?)

---

## Step 2 — Create the package

1. Go to **Packages & Passes** in the admin panel.
2. Click **New package**.
3. Fill in:
   - **Name** — What clients will see (e.g., "10-session pass").
   - **Number of sessions** — How many sessions this package includes.
   - **Validity period** — How many days after purchase it's valid.
   - **Compatible experiences** — Which experiences can be booked with this pass.
4. Set the price.
5. Save.

---

## Step 3 — Publish the package

1. Make sure the package is set to **Active**.
2. Create a publication that describes the package (or link it to an existing experience page).
3. Clients will be able to purchase it from the public site.

---

## Step 4 — Test the purchase flow

1. Create a test account (or use an existing client account).
2. Purchase the package on the public site.
3. Confirm:
   - The pass appears in the client's portal under **My passes**.
   - The session count is correct.
   - The expiry date is set correctly.
   - When booking a compatible experience, the system offers to use the pass.

---

## What happens at checkout

When a client with an active pass tries to book a compatible experience:
1. The system detects the pass automatically.
2. It asks: "Use your pass or pay directly?"
3. If they choose the pass, one session is deducted. No charge is made.

---

## Managing active packages

- Go to **Packages & Passes** to see all packages.
- You can edit pricing, extend validity, or deactivate a package at any time.
- Deactivating stops new sales — it doesn't affect passes already purchased.

---

## Monitoring pass usage

In the admin panel, you can see:
- How many sessions each pass holder has left.
- Which experiences they've used their pass for.
- Whether a pass has expired.
