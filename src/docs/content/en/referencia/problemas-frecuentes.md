# Common issues

A troubleshooting guide in plain language. Find your situation and follow the steps.

---

## My experience isn't showing up on the public site

**Check these in order:**

1. Go to **Experiences** and open the experience.
2. Make sure the status is set to **Active**.
3. Make sure there's at least one active price tier linked to it (**Pricing** tab).
4. Make sure there's a publication linked to it and the publication is set to **Active**.
5. Save and reload the public site.

If it still doesn't appear, try clearing your browser cache.

---

## A session shows "full" but I think there are still spots

1. Go to **Agenda** and open the session.
2. Check the **Capacity** field.
3. Check how many tickets have been issued for that session (go to **Tickets** and filter by that session).
4. If the count is lower than the capacity, there may be a sync issue — contact support.

---

## An order is stuck in Pending status

An order stays in Pending when payment wasn't completed.

1. Go to **Orders** and find the order.
2. If the payment was made by other means (cash, bank transfer), you can manually mark the order as paid.
3. If the payment was attempted but failed, the client needs to try again.
4. If you're unsure, check your payment provider dashboard for the transaction.

---

## A section of the docs isn't loading

If a docs page returns "not found" or the sidebar section is missing:

1. Make sure you're logged into the correct account with docs access.
2. Try navigating to the page directly using the sidebar.
3. Clear your browser cache and reload.
4. If the problem persists, contact the administrator.

---

## An image upload failed

1. Check the file format — accepted formats are JPG, PNG, and WebP.
2. Check the file size — very large files (over a few MB) may be rejected. Compress the image and try again.
3. Try a different browser.
4. If the problem continues, contact support.

---

## A ticket has the wrong status

Ticket statuses update automatically. If a ticket shows an incorrect status:

1. Open the ticket in the **Tickets** section.
2. Review the session date and current status.
3. If the status should have changed (e.g., session passed but ticket still shows "Active"), the system may need a moment to sync — wait a few minutes and refresh.
4. Administrators can update a ticket's status manually from the ticket detail view.

---

## A client can't see their tickets

1. Confirm the client is logged into the correct account (the one used at checkout).
2. Confirm the order status is not **Pending** — tickets are only generated after successful payment.
3. Go to **Clients**, find their account, and check their ticket history directly.
4. If the tickets exist in the system but don't appear for them, ask them to log out and back in.

---

## The QR code won't scan at the door

See [Using your ticket on the day](/help/docs/en/portal/validar-ticket) for full troubleshooting steps.

Short version:
- Maximize screen brightness.
- Hold the phone 15-20 cm from the scanner.
- Staff can look up the client by name or email as a backup.

---

## A client can't reset their password

1. Make sure they're checking the correct email inbox (and spam folder).
2. Have them wait a few minutes and try again.
3. Go to **Clients** in the admin panel, find their account, and manually trigger a password reset from there.

---

## The wrong price is showing on an experience page

1. Go to **Experiences** → **Pricing**.
2. Check which price tiers are active.
3. Deactivate any outdated prices.
4. Confirm the correct price is set to **Active**.
5. Reload the public page.
